SUNSIDE RACING -> GODOT: 16. GAME FLOW AND INTEGRATION
(Build incrementally: wire each component in as it lands; do a final pass at the end.)

PURPOSE
The glue that main.py provides in Python: which mode the game is in, how scenes
switch, which interaction and prompt win when several are in range, what is blocked
while a mission runs, what travel must clean up, and what pauses the game.
Reference: main.py (Game: handle, _interact, _update_world, prompts, render order).

HOW IT WORKS
- Modes (exactly one active): WORLD (driving or on foot), INTERIOR (home, store,
  farmhouse, fair, factory, island center; each a level with its own walker bounds
  and camera limits), RACE (drag race, center race, island race, tournament race),
  plus fishing (a sub-state of WORLD on foot). The world scene stays loaded
  (hidden/paused) during interiors and races and is restored on return.
- Overlays (on top of any mode; only the top one gets input; gameplay pauses while
  any is open): modal panel, pause menu, world map, inventory, orders, spend menu,
  market board, badge board, arcade, fair booth game. Input goes to the first open
  one in this order: inventory, market board, badge board, orders, arcade, world
  map, pause menu, spend menu, panel, fair booth, then gameplay.
- E (interact) priority, in the WORLD on foot (first match wins):
  1. fishing in progress -> cast again
  2. General Store door -> enter
  3. home front door (only when out of the car's reach) -> enter home
  4. ferry kiosk -> ferry
  5. island club camp -> club info
  6. island racing center -> enter
  7. Mining Factory door / depot / cargo dock
  8. Snow Fair ticket booth
  9. farmhouse door (claim / enter / abandoned)
  10. farm plot tile (owned farm, no mission) -> tend
  11. farm buyer
  12. mission giver (locked veteran / busy / offer)
  13. mainland racing center
  14. fish trader
  15. pier end -> fish
  16. car within reach -> get in
  In the car: E steps out when nearly stopped (< 15 px/s).
  Interiors dispatch E to their own nearest spot.
- Prompt priority mirrors the same order, then "E Get in", then the island
  travel prompt ("T ..."), then "Q Call car" (car > 320 px away).
- Mission lock: while a mission is active these refuse with "Finish your current
  mission first.": home, farmhouse, farm plot (it just waits), fair gate, factory,
  depot, dock, island center, ferry, givers, centers, buyers, orders, fishing piers,
  island travel. The General Store has no lock. Match main.py exactly: port each
  check where its interaction is, and grep main.py for the message to find them.
- Travel and GO HOME cleanup (fast travel, beach travel, island travel, GO HOME,
  spawn choice): leave any interior; the store cart goes back on the shelves; a
  running stone machine run is collected first; a fair ride or booth game ends;
  fishing stops; the walker is removed and the player is in the car; zoom snaps to
  driving. GO HOME only when no mission or race is running.
- Races: entering a race hides the world; the race reports its result; the player
  returns on foot beside the giver / center (car called nearby) with the result
  panel; autosave.
- Pause: Esc or window focus lost opens the pause menu (not during the title).
- HUD place line: "Highway" when on the highway (world.on_highway), else the
  region / interior room name.
- Frame order: update the active mode (skipped while an overlay pauses it) ->
  render the world or level -> HUD -> overlays -> guide arrow last.

ASSETS
None of its own.

CONNECTIVITY
Touches every component: it owns the mode switch, the input routing, and the
interaction/prompt dispatch. Each component exposes near(x,y) -> spot, prompt(spot),
and interact(spot) so the dispatcher just walks the priority list.

AS BUILT (2026-09-28, first pass: components 0-5 wired; 6-15 wire in as they land)
- scenes/main.tscn (Main, the project's main scene): the title screen until PLAY (the
  game scene loads only then), EXIT quits (tests: quit_on_exit off, exit_requested).
  skip_title starts straight in the game.
- scenes/game.tscn (Game, scripts/game/game.gd): World, Life (traffic/parking/people),
  Car, Walker, GameCamera, PlayerController, and the HUD, map, pause and panel layers.
  Opens at home in the car (HOME_PARK), driving zoom.
- Modes: "world", "interior", "race". enter_interior(node) (needs level or is a
  Level, bounds, entry; optional room_name, update, interact, exit_spot) /
  leave_interior(by_travel); start_race(node) (update(delta, move), optional respawn)
  / finish_race(return_to, show_result) -> on foot beside it (return_beside: nearest
  clear spot, car called, WALK zoom), the result panel, Autosave.request(). The world
  hides (not freed) while another mode runs.
- Pausing: Game.frame(delta, move, run) steps the active mode only while no overlay
  is open (traffic, races, timers wait; the HUD still draws). This replaced pausing
  the tree (Overlays.pause_game now defaults off): same effect, and tests can drive
  frames. Esc or losing window focus opens the pause menu.
- Overlays: input goes to the first open overlay in Overlays.ORDER (inventory,
  market, badges, orders, arcade, map, pause, spend, panel, fair_game); each overlay
  pushes itself with its kind. Gameplay input (Game._unhandled_input) only when none
  is open.
- E: in the car, step out under 15 px/s; on foot, register_interaction(key, name,
  near, prompt, interact) with key from Game.PRIORITY (fishing 1 ... car 16); the first
  in range wins, and prompt() follows the same order, then island_prompt, then
  "Q   Call car". The car's "E   Get in" is registered now; each component registers
  its own. In an interior E goes to interior.interact(player).
- Mission lock: refuse_during_mission(title) shows "Finish your current mission
  first." while mission_active() is true; each locked interact() calls it first.
- Travel: prepare_travel() leaves any interior, runs add_travel_cleanup() callables
  (store cart back, stone run collected, ride / booth game ended, fishing stopped),
  puts the player in the car, snaps the driving zoom; travel_to(pose), go_home().
- Hooks for later plans: mission_active, mission_target (yellow arrow), missions_data
  (save), island_prompt, menu_handlers ("travel", "dock", "spend", "abort",
  "quit_race"), refresh_landmarks(buyers, ferry, clubs, club_names). Veteran givers
  come from people.json (names "Veteran <Region> <Title>").
- Autosave: collect = Game.save_payload (car, walker on foot, missions dict);
  can_save = not in a race.
- HUD place line: "Highway" on the highway, else the region, or the interior's
  room_name; guide line from the picked landmark or the nearest racing center.
- The dev scene scenes/world/world_drive.tscn was replaced by scenes/game.tscn.
- Tests: tests/integration/test_game_flows.gd (22). Ported from test_game_flows.py:
  title (3), opens at home, GO HOME, no guide until a landmark is picked, map colors
  and landmarks, mission target arrow, eased zoom, get out/in zoom, travel snaps zoom,
  no map during races. Framework: priority, prompt order, mission lock, pause-menu
  sets, race return, interiors + GO HOME cleanup, overlays pause traffic, overlay
  input order, focus loss, place line, autosave payload.
