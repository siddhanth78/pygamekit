SUNSIDE RACING -> GODOT: 2. WORLD (FIXED MAP)

DECISION (user, 2026-09-28)
The world is a permanent fixed map: exactly the world the Python game generates
from seed 2026, exported once and loaded as data in Godot. The world generator is
NOT ported. Nothing about the world depends on a seed or RNG in Godot. Every fixed
site (home, General Store, farm, Snow Fair, Mining Factory, piers, ferry docks,
racing centers, camps, island camps) is exactly where it is today.

PURPOSE
Load and stream the fixed 64 x 64 sector map, and answer the world queries every
other component uses. Reference for what exists: world.py, highway.py, fair.py /
factory.py / farm.py / island.py / fishing.py site code (only for the export).

STEP 1: EXPORT (Python; BUILT 2026-09-28)
export_world.py in the Python project (tests: test_export_world.py) writes the
player's world (world.json's seed 2026 and cached sectors; the rest generated the
same way; the 568 cached sectors match the generator exactly) into the Godot
project's export/ folder (with .gdignore). Re-run it any time:
    cd "pygamekit/Sunside Racing" && python3 export_world.py
Output (full format in export/README.md):
- world/sectors/sector_<sx>_<sy>.json x 4,096: ground (64 x [terrain name,
  rotation]), roads ([lx, ly, road name, rotation]), sprites ([atlas, name, x, y, w,
  h, rotation, solid_w, solid_h]) in draw order. Verified: all 4,096 rebuild exactly
  what the Python game draws.
- world/regions.json (64 x 64 region codes), world/highway.json (hwy/ramp
  centerlines, half widths, lane), world/sites.json (home, store, farm, fair,
  factory, piers, ferry, centers, camps, fish traders, island club camps),
  world/traffic.json (272 cars with paths, 103 parked commuters with trip paths),
  world/pedestrians.json (456 groups + road walkers), world/people.json (30 givers,
  32 farm-buyer spots per region).
- tracks/center_<region>_<race>.json x 55 (5 regions x 10 + island x 5): corner
  tiles, laps, rival rating.
- samples.json: 7,600 points with region, surface, ice, highway, road, drivable,
  pier, walker_fits, car_fits: the Godot World must give the same answers.
- export_manifest.json: versions, counts, sha256 per file.
ROTATION: Python rotations turn counterclockwise on screen (art and solid boxes
alike): in Godot, rotation_degrees = -rotation. Game-logic headings are clockwise
from north. Solid boxes block cars and people alike.

STEP 2: IMPORT (Godot)
- An EditorScript (res://tools/import_world.gd) turns the export into resources:
  per-sector (or per 4x4-sector chunk) scenes with a TileMapLayer for ground, one
  for roads, and batched sprites (MultiMeshInstance2D per atlas, or Sprite2Ds for
  the few interactive ones), plus a collision list of solid rects per sector.
  Output: res://world/chunks/*.tscn and res://world/data/*.tres/json (sites,
  traffic, givers, regions). Re-runnable; overwrites the generated folder only.
- After import the map can be edited by hand in the editor. If you edit it, the
  export is no longer the source of truth: the Godot files are.

STEP 3: RUNTIME
- Streaming: load chunk scenes near the camera (view + 96 px margin, plus a ring
  of preloaded neighbours with ResourceLoader.load_threaded_request), free far ones.
- Queries (the Level interface): region_at(x,y) (regions grid), surface_at (region,
  highway asphalt = city, snow roads = ice), is_ice, road_at (road tiles + highway
  paths), can_place_car(rect), can_place_walker(rect), nearby_obstacles(x,y),
  visible_sprites. Sites/traffic/givers come from the imported data files.
- No world cache and no world.json: the map ships with the game. The player save
  only holds player state.
- Only the dynamic layer is simulated: traffic, commuters, pedestrians, fair
  visitors, animals, farm plot crops, buyers (see their plans).

WHAT STAYS GENERATED AT RUNTIME (not part of the map)
- Tournament tracks (a new set each tournament) and mission drag circuits (per
  offer): keep track_gen in Godot for these (see 8-racing-centers). Their seeds
  are strings (e.g. "<tournament>-<race>") hashed in Godot; layouts differ from
  Python's but follow the same rules.
- Mission offers, fishing, market margins, fair games: ordinary gameplay RNG.

ASSETS
All world art is referenced by the export (atlas + sprite name): terrain-, road-,
highway-, structure-, prop-, camp-, canopy-, vehicle-atlas (parked cars), and the
site art from fair-, factory-, island-, farm-atlas. No new art.

CONNECTIVITY
- Provides the Level interface to 1-car, 3-on-foot, 4-traffic-and-people.
- Provides fixed data to 4 (routes, groups), 5-ui (map regions, roads, landmarks),
  7-missions (givers), 8-racing-centers (center tracks), 9-fishing (piers,
  traders), 10-store, 11-home, 12-farm (site, buyer spots), 13-fair,
  14-factory, 15-island (docks, camps, center).
- Needs 0-foundation (Atlas).

DONE WHEN
- A side-by-side check: screenshots of the same spots (home, city center, each
  racing center, store, farm, fair, factory, each pier, ferry docks, a jungle camp,
  an island camp) in Python and Godot match.
- Every sector loads; roads connect across sectors; the highway is continuous.
- Frame time stays low with streaming; only near chunks are in the tree.
- region_at / surface_at / can_place_car agree with Python on a grid of sample
  points (export a few thousand samples with expected answers and test them).
